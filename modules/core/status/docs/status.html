    IRIhttps://www.construct-x.org/ontology/status#hasCurrentStatus
    Labels has current status [en]
    hat aktuelle Statusangabe [de]
    Comments Optionally identifies the uniquely latest known assignment per resource and status kind in the supplied data. Order uses referenceDate and referenceTime with UTC offsets, then explicit predecessor order for equal instants. Unresolved latest ties prohibit a current link; recordedAt does not determine order. Explicit hasStatus membership is required. Validation checks but does not set the link. [en]
    Bezeichnet optional die eindeutig neueste bekannte Angabe je Bezugsobjekt und Statusart im bereitgestellten Datenbestand. Maßgeblich sind referenceDate und referenceTime mit UTC-Offset sowie bei gleichen Zeitpunkten die explizite Vorgängerreihenfolge. Ungeklärte Gleichstände beim neuesten Stand erlauben keinen aktuellen Verweis; recordedAt bestimmt die Reihenfolge nicht. Ein explizites hasStatus ist erforderlich. Die Validierung prüft den Verweis, setzt ihn aber nicht. [de]
