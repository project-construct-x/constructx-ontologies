# Contribution Guide

New contributions must respect the separation of T-Boxes, A-Boxes, shapes, profiles, and reference data.

<a id="ablauf-fuer-neue-module"></a>

## Workflow for New Modules

1. Clarify the purpose and module type.
2. Assign responsibilities.
3. Create the module structure with `module.yaml`.
4. Populate the ontology IRI, namespace, and imports only from verifiable sources.
5. Add validation and tests.
6. Conduct a review.

Domain axioms, external dependencies, and published IRIs must not be guessed.
