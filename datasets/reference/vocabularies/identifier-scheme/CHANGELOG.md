# Changelog

## 0.2.0 - 2026-08-20

- Added the stable `nuts-2` datatype IRI for NUTS level 2 region identifiers.

## 0.1.0 - 2026-08-18

- Added four stable RDF datatype IRIs for the ISO 3166 identifier schemes used by the country and administrative-area vocabularies.
- Published the vocabulary graph with a stable IRI, SemVer version IRI and hash namespace.
