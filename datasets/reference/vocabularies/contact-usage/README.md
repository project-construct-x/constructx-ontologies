# Construct-X Contact Usage

Kontrolliertes Referenzvokabular fuer Nutzungskontexte von `conx-contact:ContactPoint`.

## Version 0.1.0

Enthaltene Werte:

- `contact-usage:private`
- `contact-usage:business`
- `contact-usage:official`

`contact-usage:private` ist keine Zugriffsbeschraenkung, sondern eine fachliche Aussage zur Verwendung des Kontaktpunkts.
