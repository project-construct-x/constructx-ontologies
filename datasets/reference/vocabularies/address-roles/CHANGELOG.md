# Changelog

## 0.3.0 - 2026-11-19

- Retyped the eleven existing role concepts as `conx-addr:LocationRole` using their stable IRIs.

## 0.2.0 - 2026-08-20

- Added Legal Address, Headquarters Address and Physical Location Address roles for Gaia-X address assignments.
- Kept Legal Address distinct from Registration Address because the concepts are not universally equivalent.

## 0.1.0 - 2026-08-18

- Added the initial SKOS concept scheme with eight controlled address roles.
- Aligned Delivery, Postal, Registration, Residence and Return terminology with OASIS UBL 2.5 CS01.
- Documented Invoice, Construction Site and Construction Site Access as Construct-X-specific roles without direct UBL equivalents.
- Added bilingual preferred labels, definitions, stable notations and provenance notes.
- Published the graph with a stable vocabulary IRI, SemVer version IRI and hash namespace.
